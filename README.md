## 📖 About

AEngine is a custom 2D game engine written in C# on top of MonoGame.  
Designed to be simple, fast, and easy to use for indie game development.

---

## ✨ Features

- 🎮 Component-based entity system
- 🏃 Fixed & variable update loop
- 🎨 Sprite & animation system
- 📷 2D camera with zoom and follow
- ⚡ Custom 2D physics engine
- 🖱️ Keyboard & mouse input handling
- 🔊 Room / scene management
- 🌀 Random helper with seed support

---

## 🚀 Getting Started

```bash
git clone https://github.com/StoneSoupStudio/AEngine.git
```

1. Open the solution in **Visual Studio** or **Rider**
2. Build the project
3. Reference `AEngine.dll` in your game project

---

## 📋 Requirements

- .NET 8.0
- MonoGame 3.8+
- Windows
